# 참조 문서 투입 안내

여기에 세 파일을 넣으면 Phase 2(업무 가이드)가 동작한다.

| 넣을 파일 | 파일명 |
|---|---|
| 2026 개별업무목표 | `goals-2026.md` (또는 .pdf / .docx / .xlsx) |
| 팀 업무분장·조직도 | `org-roles.md` (또는 .pdf / .docx / .xlsx) |
| 구매규정·전결규정 | `purchasing-rules.md` (또는 .pdf / .docx) |

넣은 뒤 대화형 세션에서 "참조 문서 투입했어, 역할 요약 만들어줘"라고 하면 work-guide가 운영 기준 페이지의 "역할·권한 요약"과 "근거 문서 버전" 표를 채운다.

md로 변환해 넣으면 조항 검색이 빠르고 정확하다 (pdf는 페이지 단위로 읽어야 한다).

이 폴더의 문서는 회사 내부 자료다. 버전 관리 도구(git 등)에 올리지 않는다 — `.gitignore`에 포함돼 있다.
