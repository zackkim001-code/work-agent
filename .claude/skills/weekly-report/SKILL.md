# weekly-report

## 입력

- 기간: 지난주 월요일 00:00 ~ 일요일 24:00 (KST). "이번 주"라고 하면 이번 주 월요일부터 오늘까지.
- 업무 로그: 기간 내 `상태=확정`, 프로젝트별·날짜순.
- 할 일: 기간 내 생성된 것, 기간 내 `완료`로 바뀐 것, 현재 열린 것 (기한 있는 것 우선).
- 양식: 운영 기준 페이지 "주간보고 양식" 섹션. 비어 있으면 기본 양식:
  ```
  ## <프로젝트명>
  ### 금주 진행
  ### 이슈·협의 필요
  ### 차주 계획
  ```
- 확인대기·장기대기 건수 (내용은 읽지 않는다).

## 규칙

1. 양식의 칸을 순서대로 채운다. 채울 내용이 없는 칸은 **"해당 없음"**.
2. 모든 문장은 근거 로그가 있어야 한다. 문장 끝에 `(9/16)`처럼 로그 날짜를 붙인다. 근거가 없으면 쓰지 않는다.
3. 금주 진행 = 진행·결정 로그. 이슈·협의 필요 = 이슈·요청 로그 + 미해결 상충. 차주 계획 = 열린 명시 할 일 (기한순) + 추정 할 일은 "(검토)" 표시로 끝에.
4. 상단에 한 줄: "※ 미확인 수집 N건 제외 (금요일 오후 이후 수집분은 월요일 17시 확인 후 반영)". 0건이면 생략.
5. 산문은 짧게, 보고서 문체(~함, ~예정). 대화체 금지.

## 출력

- 주간보고 모음 페이지(`3df9b92a-6770-8162-934e-d47f5c902a37`) 아래에 `주간보고 YYYY-Www` 페이지 생성. 같은 제목이 이미 있으면 본문을 교체한다 (수동 재생성 케이스).
- 호출자에게 페이지 URL과 핵심 요약 3줄(프로젝트별 한 줄)을 돌려준다.

## 검증

- 규칙 기반: 양식의 모든 칸이 존재하고 비어 있지 않은가.
- 자기 검증: 근거 날짜가 없는 문장이 있는가 → 지운다.
- 실패 시 1회 재시도. 재실패면 호출자에게 "생성 실패"와 사유를 돌려준다.
